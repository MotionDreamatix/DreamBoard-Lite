# Contributing

Thanks for wanting to help! One thing to know up front:

**This repository is generated.** DreamBoard Lite is published from the
main DreamBoard codebase — pull requests merged here would be
overwritten by the next sync. So:

- **Issues welcome** — bug reports, typos, broken links, suggestions.
- **PRs are ported, not merged** — if you send a fix, we apply it to
  the source codebase (where it lands in Lite *and* the paid editions)
  and credit you in the release notes.
- Want the full picture? The complete kit (all 56 pages,
  React + fullstack editions) is on
  [Gumroad](https://motiondreamatix.gumroad.com/l/dreamboard).

Questions: [motiondreamatix.de](https://motiondreamatix.de)
